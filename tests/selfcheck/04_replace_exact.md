# 04. Точечная правка: replace + diff

- Уровень: **L1**
- Время: ~3 мин
- Инструменты: `code_editor` (replace, read)
- Dangerous mode: не нужен

## Подготовка

Создай файл `project/config.py`:

```python
HOST = "0.0.0.0"
PORT = 8000
TIMEOUT = 30
RETRIES = 3
```

## Задание

1. Замени значение `TIMEOUT` с `30` на `60`, не задев `PORT = 8000` и `RETRIES = 3`.
2. Покажи diff изменения.
3. Подтверди, что изменён ровно один фрагмент.

## Критерии приёмки (проверь сам)

- [ ] Использован `code_editor action=replace` (не `write` целого файла).
- [ ] Ответ инструмента содержит `"changed": true` и непустой `diff`.
- [ ] В файле теперь `TIMEOUT = 60`; `HOST`, `PORT`, `RETRIES` не изменились.
- [ ] Контрольное чтение показывает ровно ожидаемое содержимое.

## Формат отчёта

```
## Отчёт по задаче 04

  - [ ] read → содержимое совпадает
```

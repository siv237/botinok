# 05. Мультиправка одним вызовом (apply, атомарно)

- Уровень: **L2**
- Время: ~4 мин
- Инструменты: `code_editor` (apply, read)
- Dangerous mode: не нужен

## Подготовка

Создай файл `project/consts.py`:

```python
HOST = "0.0.0.0"
PORT = 8000
TIMEOUT = 30
RETRIES = 3
```

## Задание

Одним вызовом примени **три** правки:

1. `HOST = "0.0.0.0"` → `HOST = "127.0.0.1"`
2. `PORT = 8000` → `PORT = 8080`
3. `TIMEOUT = 30` → `TIMEOUT = 60`

## Критерии приёмки (проверь сам)

- [ ] Использован **один** вызов `code_editor action=apply` с `edits` из трёх
      элементов.
- [ ] Ответ содержит `"ok": true`, `"changed": true` и `applied` длиной 3.
- [ ] Итоговое содержимое: `HOST`, `PORT`, `TIMEOUT` изменены, `RETRIES = 3` нетронут.
- [ ] Не делал три отдельных `replace`.

## Дополнительно (проверка атомарности)

Если одна из правок не найдена — весь вызов должен провалиться **без изменения
файла**. Сделай контрольный вызов `apply` из двух правок, где вторая заведомо
отсутствует (например `NOSUCH = 1`). Убедись, что:

- [ ] вернулся `"ok": false` с `error.code`;
- [ ] файл не изменился (`changed` в прошлом состоянии сохранилось, содержимое то же).

- Ошибки/тупики:

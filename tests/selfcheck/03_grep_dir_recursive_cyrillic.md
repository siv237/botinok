# 03. grep по каталогу: рекурсия и кириллица

- Уровень: **L1**
- Время: ~5 мин
- Инструменты: `file_system` (grep, list)
- Dangerous mode: не нужен

## Подготовка

Создай файлы:

`project/docs/a.md`
```
Нагрузка на сервер высокая.
CPU idle 40%, память в норме.
VRAM свободно 24GB.
```

`project/docs/sub/b.md`
```
Под нагрузкой понимают число запросов в секунду.
При высокой нагрузкой сервер деградирует.
Отчёт: 315 tok/s.
```

`project/docs/c.txt`
```
нагрузка не упоминается здесь.
```

## Задание

1. Найди **рекурсивно** во всём `project/docs/` все строки, содержащие корень
   `нагрузк` (любое окончание: нагрузка, нагрузкой, нагрузке…).
2. Перечисли `файл:строка` и текст совпадений.
3. Скажи, сколько всего совпадений и в скольких файлах.

## Критерии приёмки (проверь сам)

- [ ] `grep` вызван с `path=project/docs`, `recursive=true`, regex `нагрузк`
      (регистронезависимо).
- [ ] Найдены совпадения в `a.md` (1), `sub/b.md` (2), `c.txt` (1) — итого 4
      совпадения в 3 файлах.
- [ ] Строка «нагрузка не упоминается здесь» тоже найдена (словоформа).
- [ ] Номера строк соответствуют файлам.

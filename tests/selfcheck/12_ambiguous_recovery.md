# 12. Восстановление после неоднозначной правки

- Уровень: **L3**
- Время: ~8 мин
- Инструменты: `code_editor` (replace, read, apply), `file_system` (grep)
- Dangerous mode: не нужен

## Подготовка

Создай файл `project/dup.py`:

```python
def handler():
    return "same"


def other():
    return "same"
```

## Задание

1. Попробуй заменить `return "same"` на `return "changed"`, **не указывая контекст**.
2. Инструмент должен вернуть неоднозначность. Зафиксируй точный ответ: код ошибки,
   число совпадений, список кандидатов с номерами строк.
3. Действуя по этому ответу, внеси правку **только в `handler`** — так, чтобы
   `other` остался прежним.
4. Объясни, какой сигнал инструмента и как ты использовал.

## Критерии приёмки (проверь сам)

- [ ] Первый `replace` вернул ошибку `ambiguous` (или `ambiguous_fuzzy`) с
      кандидатами/числом совпадений — правка **не** применена.
- [ ] `other` не изменён; `handler` возвращает `changed`.
- [ ] Использован контекст (несколько строк вокруг) либо `replace_all` осознанно —
      но результат именно асимметричный.
- [ ] В отчёте дословно приведён ответ инструмента на шаге 2.

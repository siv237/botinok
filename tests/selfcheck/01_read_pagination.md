# 01. Чтение с пагинацией

- Уровень: **L1** (базовый)
- Время: ~3 мин
- Инструменты: `code_editor` (read)
- Dangerous mode: не нужен

## Подготовка

Создай в сессии файл `project/notes.txt` со следующим содержимым (30 строк):

```
строка 01 — вводная
строка 02 — контекст
строка 03 — цель
строка 04 — ограничения
строка 05 — план
строка 06 — шаг 1
строка 07 — шаг 2
строка 08 — шаг 3
строка 09 — проверка
строка 10 — КЛЮЧ: значение A
строка 11 — примечание B
строка 12 — КЛЮЧ: значение C
строка 13 — шум
строка 14 — шум
строка 15 — шум
строка 16 — шум
строка 17 — шум
строка 18 — шум
строка 19 — шум
строка 20 — шум
строка 21 — шум
строка 22 — шум
строка 23 — шум
строка 24 — шум
строка 25 — шум
строка 26 — шум
строка 27 — шум
строка 28 — шум
строка 29 — шум
строка 30 — конец
```

## Задание

1. Не читая файл целиком, прочитай только **строки 10–12**.
2. Назови значения из строк «КЛЮЧ».

## Критерии приёмки (проверь сам)

- [ ] Файл `project/notes.txt` создан и содержит 30 строк.
- [ ] Для чтения использован `code_editor action=read` с `offset`/`limit`
      (в ответе инструмента видно `lines 10-12 of 30`).
- [ ] В ответе названы ровно: строка 10 → «значение A», строка 12 → «значение C».
- [ ] Файл целиком не читался (не было `read` без `offset`/`limit` по этому файлу).

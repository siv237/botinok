# 06. Нечёткая правка (fuzzy) по отступам

- Уровень: **L2**
- Время: ~4 мин
- Инструменты: `code_editor` (replace, read)
- Dangerous mode: не нужен

## Подготовка

Создай файл `project/mathx.py`:

```python
def add(a, b):
    return a + b


def sub(a, b):
    return a - b
```

## Задание

Замени реализацию `sub` на `return b - a`. **Важно:** в задании
`old_text` намеренно дан с другими отступами (2 пробела вместо 4 и лишний пробел
перед `:`) — точного совпадения не будет:

```
def sub(a, b) :
  return a - b
```

Инструмент должен применить правку по нечёткому совпадению.

## Критерии приёмки (проверь сам)

- [ ] `replace` вернул `"changed": true`.
- [ ] В `applied` указано `"matched": "fuzzy"` и корректная строка.
- [ ] Итоговое содержимое: `sub` возвращает `b - a`, `add` не изменена.
- [ ] Если бы точного и похожего совпадения не было — инструмент вернул бы
      `old_text_not_found` с блоком `nearest`, а не молчаливую ошибку.

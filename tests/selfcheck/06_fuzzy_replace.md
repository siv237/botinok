# 06. Нечёткая правка (fuzzy) по отступам

- Уровень: **L2**
- Время: ~4 мин
- Инструменты: `code_editor` (replace, read)
- Dangerous mode: не нужен

## Подготовка

Создай файл `project/mathx.py`:

```python
def add(a, b):
    return a + b


def sub(a, b):
    return a - b
```

## Задание

Выполняй шаги **строго по порядку**.

### Шаг 1 (сначала). Граница возможностей — внутристрочное искажение

Fuzzy нормализует отступы и переводы строк, но **не** внутристрочные изменения.
Проверь это на исходном файле: попробуй `replace` со `old_text`, где испорчена
сама строка — лишний пробел перед двоеточием:

```
def sub(a, b) :
  return a - b
```

Ожидаемое поведение — **не** правка, а `old_text_not_found` с блоком `nearest`
(строка и ratio, ≈0.5 на двухстрочном фрагменте), потому что тело `return a - b`
ещё совпадает, а сигнатура — уже нет. Убедись, что файл **не изменён**.

### Шаг 2. Основная задача — дрейф отступов

Замени реализацию `sub` на `return b - a`. `old_text` дан с другими отступами
(2 пробела вместо 4), сигнатура при этом точная:

```
def sub(a, b):
  return a - b
```

Точного совпадения не будет — инструмент должен применить правку по нечёткому
совпадению отступов. Новое тело пиши с отступом в 4 пробела, как в `add`.

## Критерии приёмки (проверь сам)

- [ ] Шаг 1: `old_text_not_found` + `nearest` (строка и ratio ≈0.5), файл не изменён.
- [ ] Шаг 2: `replace` вернул `"changed": true`.
- [ ] В `applied` указано `"matched": "fuzzy"` и корректная строка.
- [ ] Итоговое содержимое: `sub` возвращает `b - a` (отступ 4 пробела), `add` не изменена.
- [ ] Контрольное чтение подтверждает результат.

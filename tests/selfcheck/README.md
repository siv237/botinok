# Самотестирование агента «Ботинок»

Набор нумерованных MD-заданий для проверки агентных навыков. Файлы подаются
модели **напрямую**: открой нужный `NN_*.md` и передай его содержимое агенту как
запрос. Каждая задача самодостаточна: содержит подготовку (что создать),
задание, критерии приёмки и формат отчёта — модель исполняет и **сама себя
проверяет**.

Прогрессия: L1 → L4, каждая следующая задача сложнее и опирается на предыдущие.
Идти по порядку; не пропускать.

## Как запускать

1. Запусти `botinok` в сессии с пустой папкой `project/`.
2. Открой `NN_*.md`, скопируй **весь файл** в чат агенту.
3. Агент создаёт фикстуры, выполняет задание и в конце выдаёт отчёт PASS/FAIL по
   критериям с указанием инструментов, которыми проверял.
4. Оцени по `SCORECARD.md`.

Уровни 13–15 требуют **dangerous mode** (запуск кода/тестов через `shell_exec`).
Остальные работают в безопасном режиме (только `file_system`, `code_editor`,
`session_memory`, `web`).

## Общие правила

- Пути можно давать как `project/notes.txt`, так и просто `notes.txt` — оба
  варианта резолвятся в папку `project/` сессии; двойного `project/project/`
  больше не будет.
- Нельзя менять сами критерии приёмки. Нельзя «объявлять» успех без доказательства.
- Каждый пункт отчёта подтверждается выводом инструмента (файл:строка, diff,
  `grep`), а не пересказом.
- Если инструмент вернул ошибку — это не провал задачи, а материал: покажи, что
  вернул инструмент и как ты это использовал (см. задачу 12).
- Все правки — внутри `project/` сессии; вне сессии нужен dangerous mode.
- Запрещено «обходить» инструменты: для чтения — `read`/`grep`, не `shell_exec`;
  для правки — `code_editor`, не shell-редиректы.

## Формат отчёта (в конце каждой задачи)

```
## Отчёт по задаче NN
- PASS/FAIL: <итог>
- Критерии:
  - [PASS/FAIL] <пункт> — доказательство: <tool(...) → вывод/строка>
- Использованные инструменты: <список с числами вызовов>
- Ошибки/тупики и как выкрутился: <кратко или "нет">
```

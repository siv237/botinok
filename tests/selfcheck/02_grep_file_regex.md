# 02. grep по файлу: регулярное выражение

- Уровень: **L1**
- Время: ~3 мин
- Инструменты: `file_system` (grep)
- Dangerous mode: не нужен

## Подготовка

Создай файл `project/app.py`:

```python
import os


def alpha():
    return 1


def beta(x):
    return x + 1


class Gamma:
    def method(self):
        return 2


def delta():
    return 3
```

## Задание

1. Найди все **объявления функций** верхнего уровня в `project/app.py`.
2. Перечисли их имена и **номера строк**.
3. Отдельно ответь: входит ли `method` (метод класса) в результат — и почему.

## Критерии приёмки (проверь сам)

- [ ] Использован `file_system action=grep` с `path` = **путь к файлу**
      (не каталог) и regex `^def `.
- [ ] Найдены ровно `alpha`, `beta`, `delta` с корректными номерами строк.
- [ ] `method` не заявлен как результат верхнего уровня (он с отступом).
- [ ] В отчёте приведён вывод инструмента, а не пересказ.

# Бесконечная прокрутка (Scrollback Buffer) - Botinok

## Что реализовано

Бесконечная прокрутка истории сессии без разрывов между диалогами. Все сообщения сохраняются в общей последовательности.

## Управление прокруткой

| Клавиша | Действие |
|---------|----------|
| `↑` (стрелка вверх) | Прокрутка вверх на 3 строки |
| `↓` (стрелка вниз) | Прокрутка вниз на 3 строки |
| `PgUp` | Прокрутка вверх на страницу |
| `PgDown` | Прокрутка вниз на страницу |
| `Home` | Перейти к началу сессии |
| `End` | Перейти к концу сессии |

## Интерфейс

- **Заголовок панели контента**: `History (start-end/total) %` - показывает текущую позицию
- **Полоса прокрутки**: Визуальный индикатор справа от контента (`█` - ползунок, `│` - фон)
- **Индикатор в панели статистики**: `Scroll: PgUp/PgDown/↑↓/Home/End | AUTO/MANUAL`
  - `AUTO` - прокрутка следует за новым текстом (зеленый)
  - `MANUAL` - пользователь управляет прокруткой (желтый)

## Как это работает

1. **История загружается** из `context.json` при старте сессии
2. **Новые сообщения** добавляются в конец истории
3. **Auto-scroll** включен по умолчанию - виден конец диалога
4. При **ручной прокрутке вверх** auto-scroll отключается
5. При **прокрутке в конец** (End) auto-scroll включается

## Технические детали

- Новый класс: `core/scrollback_buffer.py`
- Интеграция в `BotVisualizer` через `self.scrollback`
- Фоновый поток `readchar` для обработки клавиш без блокировки UI
- Сохранение позиции при вызове инструментов

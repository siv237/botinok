# SCROLLBACK_FEATURE.md

> **Статус: superseded (2026-09-17).** Документ удалён из репозитория в 0.4 —
> описывал фичу Rich-эпохи (`BotVisualizer`/`readchar`), которая не была
> реализована; оставлен как историческая запись вики. → `concepts/scrollback.md`, `entities/textual_ui.md`

## Резюме (содержание документа)
- **Что**: бесконечная прокрутка истории сессии без разрывов между диалогами; все сообщения в общей последовательности.
- **Управление**: `↑`/`↓` на 3 строки, `PgUp`/`PgDown` на страницу, `Home`/`End` — к началу/концу.
- **Интерфейс**: заголовок панели `History (start-end/total) %`; полоса прокрутки (ползунок `█`, фон `│`); индикатор `Scroll: ... | AUTO/MANUAL` (AUTO — следует за текстом, зелёный; MANUAL — ручное управление, жёлтый).
- **Логика**: история из `context.json`; auto-scroll по умолчанию; ручная прокрутка вверх отключает auto; `End` возвращает auto.

## Технические детали (по документу)
- (Историческая запись) предполагался новый класс `core/scrollback_buffer.py` с интеграцией в `BotVisualizer` через `self.scrollback` и фоновым потоком `readchar`. Оба компонента удалены в 0.4.

## ⚠️ Расхождение документ/код (противоречие)
`core/scrollback_buffer.py` **отсутствует** в git-истории (проверено `git ls-files`), фича не реализована. Актуальная прокрутка истории — Textual `textual_history_viewer.py`. Запись окончательно устарела.

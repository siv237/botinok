# История git (коммиты)

Хронология разработки из git-истории (главная ветка `main`). Source: `<repo>/.git`. → `overview.md`

## Основные вехи (в порядке истории)
1. **Начало**: «Initial commit: clean source code without IDE artifacts»; установщик, README, баннер, форматирование вывода, счётчик контекста, тихий режим/pipe.
2. **Инструменты базы**: чтение файлов (`file_system`), работа с журналами (`journal`), уплотнение контекста, режим выполнения и редактирования (`code_editor`).
3. **Промпты и сессии**: промпты вынесены в `prompts/` и клонируются в сессию; пользовательский конфиг; debug-режим; только-чат для моделей без tools; `--update`.
4. **Визуальные инструменты**: `image_ascii`, `vision` (валидация/автоконвертация в JPEG, preflight), `web_extract`, `curl`.
5. **Релиз 0.2** (fixes: ans-переменная, изображения, конфиги; RHEL; логотип).
6. **Меню сессий**: интерактивная таблица с курсорной навигацией и фильтрацией; многострочный ввод; `session_memory` (объектный доступ к истории).
7. **Переход на Textual**: замена Rich Live → Textual TUI; плавный стриминг, спойлеры, FPS, паритет интерфейсов. → `comparisons/rich_vs_textual.md`
8. **OpenAI-совместимые бэкенды** (актуально, коммит `fb084e8`): llama-server, vLLM и др. → `entities/openai_compat.md`

## Статистика
~112 коммитов; ветки: `main`, `backup-main-20260409_222705`; upstream `origin/main`. Крупные рефакторинги — интерфейс (Rich→Textual) и бэкенд (Ollama→+OpenAI-compat).

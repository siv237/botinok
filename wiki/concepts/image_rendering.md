# Отображение изображений в чате (идентификаторы + ленивый рендер)

Механика показа картинок в TUI: в сессии хранятся **только идентификаторы**,
файлы лежат в каталоге проекта, а рендер превращает идентификатор в картинку
**по мере прокрутки**.

## Разделение ответственности

| Слой | Где | Что делает |
|------|-----|-----------|
| Каталог | `core/image_catalog.py` | принимает файл/URL, кладёт в проект, выдаёт уникальный `id`, ведёт `catalog.json` |
| Маркер | `core/image_refs.py` | разбор `[[image:<id>|alt]]` → сегменты текст/картинка, резолв id → путь |
| Рендер | `core/image_render.py` | ANSI-рендер (chafa → фолбэк), кэши `ansi` и готового `rich.Text`, бюджет памяти |
| Виджет | `core/image_block.py` | ленивый `ImageBlock`: фикс. высота + видимый срез строк |
| Инструмент | `tools/image_show.py` | `image` — добавить и получить `token` для вставки в ответ |

## Почему идентификаторы, а не картинки

- `context.json` остаётся текстовым и маленьким: сотни картинок не раздувают
  сессию.
- Один файл переиспользуется по sha256 — один `id` на содержимое.
- Идентификаторы **никогда не повторяются**: `seq` хранится в каталоге и не
  сбрасывается даже при удалении; удалённый id уходит в `retired`.

## Почему «летает» даже на 4К

Замеры, из-за которых механика переделана:

1. `chafa` — 40–225 мс, уходит в **фоновый поток**, UI не блокирует.
2. `Text.from_ansi` на широком рендере — 251 мс (200 клеток), 602 мс (300),
   **1210 мс (400)**. Раньше выполнялся на UI-потоке → «свернул на весь экран и
   завис». Теперь разбор в фоне, готовый `rich.Text` кэшируется.
3. Гигантский `Static` (например, 328×122 клетки) блокировал раскладку ~1.5 с.
   Логотип-баннер ограничен (`LOGO_MAX_WIDTH=168`, `LOGO_MAX_HEIGHT=48`).
4. Для картинок чата — `ImageBlock`: контейнер **фиксированной высоты** (полная
   высота картинки, скролл корректен) и один дочерний вью, смещённый `offset`
   на начало видимого среза; разбирается только окно строк.

Итог на 4К-подобном окне (400×110) с 60 высокими картинками (200×800):
старт — 4 полных рендера из 60, срез 32 строки из 401, **провал UI 68 мс**.
Логотип-баннер на 600×160: `max_gap` 269 мс, всего 2 рендера.

## Прочие правила

- Картинка всегда на всю ширину контейнера, пропорции сохраняются, высота не
  режется (скроллится). Секстанты: ~2 пикселя по ширине на ячейку.
- В стриминге маркер маскируется (`🖼 [изображение]`), сырой `[[image:…]]` не
  светится в чате.
- Пейджер (F6) показывает картинки настоящим chafa-рендером; вырезание фоновых
  цветов при этом отключается, иначе картинка ломается (chafa задаёт цвет фоном).
- Неизвестный id → заметная пометка, без падения.

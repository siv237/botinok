# open_url — инструмент Ботинока

Плагин-папка: `tools/open_url/` (`tool.json` + `__init__.py` + этот README).
Удалишь папку — инструмент исчезнет из каталога, payload и вызовов.

- **Назначение:** Открыть ссылку и извлечь текст со страницы (использует lynx -dump)
- **Пакет:** `tools.open_url` · **Вход:** `open_url` · **Алиасы:** нет
- **Платформа передаёт в вызов:** `session_path`, `progress`
- **Схема:** ручная, из [tool.json](./tool.json) (1 параметров)
- **Always-on:** нет
- **Тесты:** — (отдельного теста нет)

## Параметры (по схеме)

| параметр | тип | обязателен |
|----------|-----|------------|
| `url` | string | да |

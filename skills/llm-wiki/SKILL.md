# LLM Wiki — знаниевая база для сложных задач

Официальный паттерн лежит рядом с этим скиллом: **`llm-wiki.md`** (в той же папке). Его текст неизменяем — это эталон, а не черновик. Скилл приказывает: сначала изучить паттерн, затем развернуть его структуру в проекте и дальше жить по нему.

## Когда применять

- Задача сложная, длинная или исследовательская: разбор чужого кода, сравнение технологий, изучение проекта, расследование, накопление знаний между шагами и сессиями.
- Контекст будет вытесняться, а знания должны оставаться.
- Простые задачи (один файл, один вопрос, пара правок) — НЕ применять.

## Порядок действий

1. **Изучи паттерн.** Файл `llm-wiki.md` лежит **в той же папке, что и этот SKILL.md** — инструмент `skills` напечатал её в строке «папка скилла: …». Читай напрямую: `file_system action=read path=<папка скилла>/llm-wiki.md`. НЕ ищи его по диску, не грепай, не гадай — путь уже известен. Не пересказывай паттерн пользователю — следуй ему. Сам файл не редактируй никогда.
2. **Найди схему.** Посмотри `AGENTS.md` / `CLAUDE.md`: если там уже описана вики проекта — работай по ней. Если вики уже есть (`wiki/`), но схемы нет — выведи схему из фактической структуры и предложи добавить в схему проекта.
3. **Если структуры нет — создай её** по паттерну:
   - `wiki/` — каталог страниц (твои, LLM-ом владея);
   - `wiki/index.md` — каталог всех страниц: ссылка + одна строка описания, категории;
   - `wiki/log.md` — append-only журнал: `## [ГГГГ-ММ-ДД] ingest|query|lint | <что>`;
   - `wiki/raw/README.md` — манифест исходников (ссылки на неизменяемые файлы);
   - раздел «Схема вики» в `AGENTS.md` проекта: слои, конвенции страниц, операции.
4. **Дальше живи по операциям паттерна:**
   - *Ingest*: прочитал источник → краткие выводы человеку → обнови все затронутые страницы → index → запись в log. Противоречия не затирай — помечай `status: superseded` со ссылкой на новый источник.
   - *Query*: сначала index → страницы → ответ с цитатами-ссылками. Ценный ответ оформи новой страницей вики (исследование не должно умирать в чате).
   - *Lint*: периодически — противоречия, устаревшие страницы, сироты, дыры в перекрёстных ссылках; итог в log.

## Железные правила

- Raw-источники неизменяемы: читаешь, но не правь. Не правь и сам `llm-wiki.md`.
- Вики владеешь ты: плотные факты, таблицы, перекрёстные ссылки; никакого красивого пересказа и выдумок — только то, что есть в источниках.
- Начал сложную задачу при существующей `wiki/` — не изучай всё заново: index → страницы → ответ.

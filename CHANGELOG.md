# Changelog

## [0.3] - 2026-08-24

### Новый интерфейс: Textual TUI
- **Textual TUI стал интерфейсом по умолчанию**; прежний Rich Live доступен через флаг `--rich-mode`
- Перенесён и доведён до состояния полностью рабочего TUI: цикл вызовов инструментов (tool-calls loop), slash-команды, markdown-рендеринг
- Независимый ввод сообщений во время стрима с очередью и остановкой по ESC
- Collapsible-спойлеры в общем потоке вместо RichLog; весь поток выводится через единую точку `stream_static`
- Живое markdown-форматирование стриминга ассистента
- Плавный стриминг и ускорение UI до 10/30 FPS
- Корректное отображение VRAM на всех этапах; заголовок окна приведён к стилю старого Rich Live
- Убран мигание стрима — `stream_static` конвертируется на месте, спойлеры закрываются по очереди
- Автопрокрутка больше не мешает скроллу мышью; сырой «мусор» мышления убран из общего потока
- Отдельный просмотр истории (`textual_history_viewer.py`)

### OpenAI-совместимый бэкенд
- Поддержка OpenAI-совместимых API (llama-server, vLLM, OpenAI и др.) через новый модуль `core/openai_compat.py`
- Исправлены зависания и `server_error` при работе с OpenAI-совместимыми бэкендами

### Улучшения мастера настройки
- Поддержка выбора бэкенда: Ollama или OpenAI-совместимый API (адрес, API-ключ, проверка списка моделей)
- Извлечение провайдерского контекста моделей и построение «лесенки» размеров контекста с рекомендацией провайдера
- Настройка контекста по умолчанию и запуск `--wizard` без `--rich-mode`
- Корректный формат списка моделей Ollama (list[dict]) для передачи в выбор модели

### Новые инструменты и возможности
- **session_memory** — объектный доступ к истории сессий (search/filter/chain/stats) через новый инструмент
- Многострочный режим ввода с нумерацией строк, навигацией по ↑↓ и отправкой по Ctrl+D
- Интерактивное меню выбора сессии: таблица с курсорной навигацией, фильтрация по вводу, относительное время; сессия создаётся только после успешного выбора действия
- Запрос подтверждения перед запуском корректора и улучшенный промпт с пошаговым алгоритмом

### Документация и вики
- Добавлена LLM-wiki проекта «Ботинок» по методике `llm-wiki` (справочник сущностей, концепций, сравнений и источников в `wiki/`)
- Добавлен скроллбеки-документ `SCROLLBACK_FEATURE.md`

### Исправления
- Исправлена ошибка `UnboundLocalError`: удалён дублирующий локальный импорт `Confirm`
- Исправлен `UnicodeDecodeError` при декодировании стрима и выводе в консоль
- Исправлена ошибка `TypeError: string indices must be integers` при выборе модели Ollama в мастере
- Контекст модели извлекается из `details.context_length` ответа `/api/tags` Ollama

## [0.2] - 2025-03-30

### Новые инструменты
- **vision** — анализ изображений мультимодальной моделью Ollama
  - Автоматическая валидация и конвертация изображений в JPEG
  - Preflight-проверка перед отправкой в Ollama
  - Проверка Content-Type для веб-изображений
- **curl** — загрузка файлов и работа с HTTP-запросами
- **web_extract** — извлечение ресурсов с веб-страниц
- **image_ascii** — ASCII-генератор изображений
- **--update** — инструмент обновления версии botinok

### Новые возможности
- Поддержка macOS
- Режим "только чат" для моделей без поддержки инструментов
- Пользовательские конфиги (в дополнение к проектным)
- Debug-режим для отладки
- Системный промт для управления поведением
- Промты вынесены в отдельную папку `prompts/`, клонируются внутрь сессии
- Опасный режим для file_system инструмента

### Улучшения
- Работа визарда при Ollama через nginx
- Оптимизация работы через SSL с Ollama
- Уменьшение мерцания в SSH-терминалах с низкой скоростью
- Компактный прогрессбар контекста
- При возврате в сессию сразу выводится последний ответ
- Улучшение автообновления с поддержкой Python-зависимостей

### Исправления
- Исправлена ошибка с переменной `ans` в file_system
- Исправлена обработка изображений с неизвестным форматом
- Исправлена валидация изображений: preflight-проверка
- Исправлена обработка ошибок сохранения конфигов

### Прочее
- Расширен скрипт установки для RHEL-систем
- Добавлен логотип в README
- Обновлена документация

# Changelog

## [0.4]

### Главное
- **Скользящее окно памяти вместо «биг-бенга»**: контекст больше не сбрасывается разом посреди работы — старые ходы плавно вытесняются, ботинок держит каталог забытого и поднимает любой по требованию
- **Картинки прямо в чате** — ботинок показывает изображения, по ssh в настоящих цветах
- **Единый инструмент `web`**: поиск, чтение страниц, скачивание с докачкой и торрентами, прокси одной командой, память загрузок
- **Встроенный терминал** над чатом вместо модальных окон, с таймером и развёрнутым показом опасных команд

### Новое
- Новый инструмент `image`: картинки в чате на всю ширину, прокручиваемые, без тормозов
- Поиск по сессии идёт по содержимому сохранённых файлов с ранжированием по релевантности
- Оборванный ответ модели автоматически продолжается и сшивается в цельный
- Инструменты включаются по запросу и не занимают контекст заранее (~8000 токенов экономии)
- Живой прогресс инструментов: скорость загрузки, «найдено N», размер/время
- Прокси настраивается одной командой и действует на весь веб-кит; помощник-навигатор подсказывает готовые действия по странице
- Окно ввода API-ключа со ссылкой на выдачу; ключ сохраняется в личные настройки
- Мастер настройки проверяет TLS-сертификат сервера и спрашивает, доверять ли ему
- `botinok --update` доустанавливает системные компоненты (chafa, ffmpeg, aria2 и др.)

## [0.3] - 2026-08-24
